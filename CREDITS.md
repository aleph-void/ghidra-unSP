## What Ghidra-Rare changed (commits on branch `ghidra-rare`)
1. `data/languages/unsp.slaspec` is now generated by `tools/gen_unsp.py` (tables instead of ~1500 hand-written
   lines); constructor patterns no longer conflict (`sleigh -l` is clean).
2. SR is the real status register; N Z S C and DS are bit ranges of it (no pack/unpack tables). Reads of SR and PC
   return the live code segment / the address after the instruction.
3. ALU flags rewritten from the ISC-licensed veesem emulator's rules (carry of `sub`/`cmp` fixed for a zero
   subtrahend; `adc`/`sbc` chains), every addressing form decoded against MAME (indirect modes, DS wrap, `[bp+n]`,
   `[n]`, shifts with the SB register, two-word forms `rd = rs op imm16/[imm16]`, `[imm16] = rs op rd`).
4. Instructions that write PC branch and leave the flags alone; `pop`/`push` (every register range and pointer),
   `retf`, `reti`, `call`, `goto`, `break`, `call mr`, `goto mr` implemented.
5. Multiplies `uu/us/ss` and inner products (`MR = [Rd]*[Rs], n`, with the FIR data move), bit operations,
   `ds`/`fr` moves, interrupt-control bits (`fir_mov on/off` were inverted), division/exp as pcodeops.
6. SECBANK is tracked as a context bit (`secb`): after `secbank on`, `r1`-`r4` are `sr1`-`sr4` (the original left
   this as a TODO).
7. The 2.0 extended group (prefix `0xff80`: `r8`-`r15`, extended addressing groups, push/pop) implemented.
8. `unsp.pspec`: dropped the `segment` userop dependency on register `ds`; vector symbols added. `unsp.ldefs`
   version bumped. The template analyzer/help stubs were removed. `build.gradle`/`extension.properties` replaced by
   the Ghidra-Rare extension build.
9. `test/`, `tools/`, `GHIDRA-RARE.md`, `README.md` (limitation list updated), this file.

## Sources used
* MAME `unidasm -arch unsp10|unsp12|unsp20` (GPL): run as a black box, never read.
* naken_asm (GPL-3, Michael Kohn), pinned commit `247c237`: run as a black box (assembler); its test table was used
  only to learn the assembler syntax.
* veesem (ISC, Simon Eriksson), commit `42fb8f0`, `src/core/spg200/cpu.cc`: read for the ALU/branch/stack semantics.
* vsmile-dev/vsmile-hardware-docs (Luke Usher and contributors; no license file): read as documentation (status register
  layout, jump conditions, push/pop, call/retf); no text copied.
* The unSP Programmer's Guide in Generalplus' IDE (see upstream issue #1) was not available; the points that need it
  are listed as unverified in GHIDRA-RARE.md.
